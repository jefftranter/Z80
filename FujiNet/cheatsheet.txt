                Heathkit H-89 FujiNet Quick Reference
                  Based on H89 FujiNet release 1.09
             Jeff Tranter <tranter@pobox.com> 13 Nov 2026

CP/M:
=====

Initial Setup:
Need 100K CP/M disk images in h8d format. Can be on a server (e.g.
TNFS) or on the FAT32-formatted microSD card.

Use:
Run FNCONFIG to configure FujiNet.
Run FNDISK to mount drives (can optionally pass first drive letter to
use).

Typical drive Assignments when booting from CF Flash:
A: - E:  CF Flash drives (D: - H: if booting from floppy)
F: - H:  Physical floppy drives (A: - C: if booting from floppy)
I: - P:  FujiNet drives, slots 1 through 8

FujiNet Devices:
LST: is assigned to UL1: (FujiNet printer). Printed document appears
on web page.
Web server appears at IP address (e.g. http://192.168.40.180/).

Utility Programs:
NPIP program is similar to CP/M PIP but also supports copying to and
from URLs (e.g. (TNFS://HOST/PATH, SD:/NAME).
NC is a program inspired by Linux netcat that supports connecting via
a URL to various protocols such as SSH, FTP, TELNET, and CPM.

HDOS:
=====

Initial Setup:
Copy FN.DVD to boot drive (e.g. SY0:).
Copy LP.DVD if FujiNet printer support is desired (back up original).
Need 100K, 200K, 400K, or 1800K HDOS disk images in h8d format. Can be
on a server (e.g. TNFS) or on the FAT32-formatted microSD card.

Use:
Run FNCONFIG to configure FujiNet.
Use MOUNT command (e.g. MOUNT FN0:) to mount FujiNet drives (under
HDOS 3, "MM FN:" will mount all FujiNet drives).

Typical Drive Assignments:
SY0: - SY7: CF Flash drives
DK0: - DK1: Physical floppy drives
FN0: - FN7: FujiNet drives, slots 1 through 8

FujiNet Devices:
LP0: is FujiNet printer. Printed document appears on web page.
Web server appears at IP address (e.g. http://192.168.40.180/).

Utility Programs:
NPIP program is similar to HDOS PIP but also supports copying to and
from URLs (e.g. (TNFS://HOST/PATH, SD:/NAME).
NC is a program inspired by Linux netcat that supports connecting via
a URL to various protocols such as SSH, FTP, TELNET, and CPM.

FujiNet Boot:
Using a special monitor ROM, you can directly load and run the FujiNet
FNCONFIG program from the H89 monitor using the command "G 17200". In
future, this should also support booting from FujiNet drives.

ESP32 Console Access:
Connect computer to ESP32 USB port, speed 460800 bps.

CP/M:
=====

Initial Setup:
Need at least 3K of high memory available (e.g. 61K CP/M system). See
documentation for details.
Can optionally store disk images in h8d format on FAT32-formatted
microSD card.

Use:
Run CONFIG to configure FujiNet.
Run FNDISK to mount drives (can optionally pass first drive letter to
use).

Typical drive Assignments when booting from CF Flash:
A: - E:  CF Flash drives (D: - H: if booting from floppy)
F: - H:  Physical floppy drives (A: - C: if booting from floppy)
I: - P:  FujiNet drives, slots 1 through 8

FujiNet Devices:
LST: is assigned to UL1: (FujiNet printer). Printed document appears
on web page.
Web server appears at IP address (e.g. http://192.168.40.180/).

Utility Programs:
NPIP program is similar to CP/M PIP but also supports copying to and
from URLs (e.g. (TNFS://HOST/PATH, SD:/NAME).

HDOS:
=====

Initial Setup:
Copy FN.DVD to boot drive (e.g. SY0:).
Copy LP.DVD if FujiNet printer support is desired (back up original
HDOS LP.DVD first).
Can optionally store disk images in h8d format on FAT32-formatted
microSD card.

Use:
Run CONFIG to configure FujiNet.
Use MOUNT command (e.g. MOUNT FN0:) to mount FujiNet drives.

Typical Drive Assignments:
SY0: - SY7: CF Flash drives
DK0: - DK1: Physical floppy drives
FN0: - FN7: FujiNet drives, slots 1 through 8

FujiNet Devices:
LP0: is FujiNet printer. Printed document appears on web page.
Web server appears at IP address (e.g. http://192.168.40.180/).

Utility Programs:
NPIP program is similar to HDOS PIP but also supports copying to and
from URLs (e.g. (TNFS://HOST/PATH, SD:/NAME).
